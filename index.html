Privacy Policy — Vehnaro: Car Service History

Last updated: 25 September 2026

Developer: Vehnaro

Privacy contact: vehnaro+support@gmail.com

Local-first storage

Vehnaro Personal does not require an account. Vehicle details, mileage, service history, parts, costs, photos, invoices and maintenance documents are stored locally in the app's private storage. Android system backup and automatic device-to-device transfer are disabled for this private data.

Maintenance documents and OCR

Vehnaro uses Google ML Kit text recognition for OCR. The OCR input and recognized text are processed on-device and are not sent to Google servers or to a Vehnaro backend. Google states that ML Kit may send separate technical metrics to Google for diagnostics and usage analytics; those metrics do not contain the OCR input or recognized text. Proposed maintenance intervals do not become active until the user reviews and accepts them.

Technical data processed by Google ML Kit

Google states that ML Kit Android SDKs collect technical information including device information, application information, per-installation identifiers, performance metrics, API configuration, feature input/output size, feature version, event type and error codes for diagnostics and usage analytics. Google states this technical data is encrypted in transit and is not transferred by ML Kit to third parties.

Exports and backups

Vehnaro only exports maintenance data when the user explicitly creates a portable backup or CSV, or chooses to share a file through Android. The user chooses the destination. Vehnaro Personal currently has no Vehnaro cloud synchronization service.

Notifications

Notification permission is used only for local maintenance reminders enabled by the user. Vehnaro does not use push advertising or marketing notifications.

Retention and deletion

Local data remains on the device until the user edits or deletes it, deletes a vehicle, clears the app's storage or uninstalls the app. Exported backup files are controlled by the user at the selected destination.

Security

Vehnaro stores its working database and private files in Android app-private storage. Release signing material is kept outside the source repository. The app does not include advertising SDKs.

Changes

This policy will be updated when Vehnaro's data handling changes. The policy shown inside the app and the public policy linked from Google Play should remain consistent.
